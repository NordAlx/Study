# eEPC: draw.io, PNG и скриншоты

Открывайте файлы .drawio на app.diagrams.net через «Файл → Открыть из → Это устройство». Все фигуры, подписи и стрелки редактируются отдельно.

- eEPC_AS_IS_TO_BE.drawio — обе модели, десять страниц.
- Основной файл каждой модели — пять страниц A0–A4.
- «Декомпозиции» — отдельный файл каждого листа.
- «PNG» — изображения для вставки в курсовую, белый фон, 300 dpi.
- «Скриншоты_drawio» — реальные снимки открытых страниц официального редактора diagrams.net, с его интерфейсом. Это обзорные снимки; для печати используйте PNG.

Стандартные редактируемые фигуры без значков SILA Union: функция — скруглённый прямоугольник; событие — шестиугольник; логический оператор — круг XOR или AND; исполнитель — эллипс; программа — прямоугольник с боковыми полосами; документ — фигура документа. AS IS: зелёные функции, без CRM. TO BE: голубые функции с технологией BPMSoft.

Сплошные линии со стрелками показывают последовательность выполнения; пунктирные дополнительные связи связывают с функцией исполнителей и программы; информационные связи документов имеют наконечники. Управляющий поток проходит по прямым участкам с прямоугольными поворотами. Документы и ресурсы стоят у своих функций; одинаковые названия обозначают повторные экземпляры одного объекта. Неиспользуемые боковые интерфейсы соседних процессов не вынесены в отдельные цепочки: границы рассматриваемых процессов показаны начальными и конечными событиями. Все шаги, развилки и циклы доработки сохранены.

Проверены все десять страниц: нет пересечений стрелок, перекрытий блоков, связей через посторонние фигуры и элементов без связей. Скриншоты получены после открытия страниц в официальном редакторе; PNG сформированы из экспорта движка draw.io по тем же редактируемым файлам.

Актуальный TO BE: офисные приложения и почтовый клиент исключены; данные, документы, переписка и отчётность ведутся в BPMSoft. Внешние инструменты оставлены только для макетов, рекламных размещений и источников мониторинга.
