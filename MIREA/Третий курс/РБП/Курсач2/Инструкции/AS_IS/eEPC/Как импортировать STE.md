# eEPC as is — единый вид

Обычным пунктом «Импорт» загрузите «EPC_AS_IS_единый вид.ste». В нём принятый верхний уровень A0 и четыре обновлённые декомпозиции A1–A4. Верхний уровень взят из успешно открытого файла без изменения его модели и объектов. Названия новых декомпозиций заканчиваются на «as is, единый вид»; открывайте эти модели вместо прежних «v3».

Для отдельного импорта используйте файлы 1_A1_eEPC_SILA.ste, 2_A2_eEPC_SILA.ste, 3_A3_eEPC_SILA.ste и 4_A4_eEPC_SILA.ste в EPC_AS_IS. Файл 0_A0_eEPC_SILA.ste теперь является точной копией принятого верхнего уровня.

Все фигуры созданы по нативным образцам того же успешно открытого верхнего уровня: функции с зелёной фигурой и стрелками, события с флажком, должности с жёлтой фигурой, программы с синей фигурой, документы с серой фигурой. Идентификаторы символов, типы объектов и стили фигур/подписей скопированы из его экспорта. AND/OR используют соответствующие нативные логические символы из ранее присланного образца. Прежние светлые цвета, произвольные параметры прозрачности и внешние шрифтовые переопределения не переносятся.

Исправлен тип функции с логическим оператором: используется «c_sila_leads_to_sila_EVENT» из вашего текущего рабочего экспорта, а не предполагаемый «c_sila_leads_to» из версии v3. Событие с оператором связано «c_sila_is_eval_by». Все типы связей взяты из нативных экспортов, новые названия типов не придумывались. Логика существующего процесса, участники, приложения, документы и контрольные маршруты сохранены. Это as is без CRM и BPMSoft.

Проверены структура архивов, ссылки на объекты, сохранение контрольных графов и соответствие нативных символов/стилей принятому образцу. Четыре новые декомпозиции в самой SILA ещё не открывались. Старые SVG/PNG/drawio из предыдущих комплектов не являются предпросмотрами этой версии; актуальными для текущей правки являются новые .ste.

Курсовая, IDEF0, BPMN, модели to be и исходный файл принятого верхнего уровня не изменены. В папке «Курсач» никаких изменений нет.
