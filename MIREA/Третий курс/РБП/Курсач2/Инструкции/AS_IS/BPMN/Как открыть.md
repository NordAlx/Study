# BPMN as is по исправленной инструкции

Основной файл «Проведение рекламных кампаний_AS_IS.bpmn» содержит полную модель: четыре встроенных раскрытых подпроцесса, дорожки с должностями, возвраты, сообщения и документы. Файл редактируется как стандартный BPMN 2.0 XML.

Для компактного редактирования и рисунков курсовой используйте пять отдельных файлов 0–4 из этой папки: верхний уровень A0, затем детализации A1–A4. В StormBPMN выберите импорт BPMN/XML и нужный файл. Каждый файл содержит координаты фигур и стрелок. Подробные описания задач включают исполнителя, средства, входы и результаты.

По сравнению с прежними файлами добавлено завершение подготовки обоих каналов до общего запуска, дата запуска из медиаплана, постоянные хранилища контактов/рассылок/документов/переписки и отдельные объекты параметров, сообщений и адресатов. Последовательные потоки находятся внутри своих процессов; сообщения проходят между разными пулами.

Повторный проход применяет согласованные изменения с учётом истории; прежняя рассылка всей аудитории не повторяется. Задачи выполняются сотрудниками, а не исполняемым процессным движком. CampaignLaunchOrChangeDate и NextManualCheckDate — обозначения дат из медиаплана, не настроенные автоматические уведомления. Текстовые условия потоков описывают решения сотрудников.

Файлы проверены официальной XSD-схемой OMG и импортом в bpmn-js. Импорт в пользовательский аккаунт StormBPMN не выполнялся. Рисунки и текст в Word не изменены.
