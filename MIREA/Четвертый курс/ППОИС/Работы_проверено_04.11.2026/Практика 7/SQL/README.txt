База данных сопровождения корпоративных продаж

Для PostgreSQL выполните в новой пустой базе файлы 01, 02, 03, затем запросы 04.
Файл 03 требует права создания ролей.
Для воспроизводимой проверки в этой папке: npm install, затем npm run check.
Скрипт использует PGlite 0.5.15, создаёт отдельную базу в памяти и сохраняет
результаты в JSON и CSV. БД_PGlite.tar.gz — снимок для PGlite.
15 таблиц, 81 поле, 60 тестовых записей; 7 запросов функциональности.
