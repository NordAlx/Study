# Практическая работа №7 — учебная база корпоративных продаж

Все данные синтетические. Это предложенная схема, а не действующая БД ПАО «ВЫМПЕЛ-КОММУНИКАЦИИ».

## Обычный PostgreSQL 18

Создайте отдельную пустую БД. В psql, находясь в этой папке, последовательно выполните:

```sql
\i 01_DDL_схема.sql
\i 02_Тестовые_данные.sql
\i 03_DCL_права.sql
\i 04_Запросы_функциональности.sql
```

Для DDL/DCL нужен владелец БД с правом CREATE ROLE. Роли crm_* создаются в кластере, поэтому их имена не должны быть уже заняты. Скрипты предназначены для первого запуска, не являются повторяемой миграцией и ничего не удаляют. Существующие рабочие базы не использовать.

## Воспроизведение автоматической проверки без сервера

Нужен Node.js. В этой папке выполните `npm install`, затем `npm run check`.
Скрипт создаёт свежую БД PGlite в памяти, выполняет DDL, наполнение, DCL, запросы и 21 проверку. Каждая контрольная операция откатывается. Исходные SQL не изменяются; результаты JSON/CSV и снимок БД перезаписываются.

Фактически использован PGlite 0.5.12, PostgreSQL 18.6 (WebAssembly). Итоговый снимок `Учебная_БД_PGlite.tar.gz` создан методом dumpDataDir(); это формат PGlite, его нельзя подключить как каталог обычного сервера PostgreSQL. Для обычного сервера используйте SQL.

Пример загрузки снимка в PGlite:

```js
import { PGlite } from '@electric-sql/pglite';
import { readFile } from 'node:fs/promises';
const data = await readFile('Учебная_БД_PGlite.tar.gz');
const db = new PGlite({ loadDataDir: new Blob([data]) });
console.log((await db.query('SELECT count(*) FROM crm.deal')).rows);
await db.close();
```

## Файлы и границы проверки

- 01_DDL_схема.sql — 15 таблиц, индексы, представление, функции и триггеры.
- 02_Тестовые_данные.sql — 60 строк.
- 03_DCL_права.sql — 11 команд GRANT/REVOKE и создание четырёх групповых ролей.
- 04_Запросы_функциональности.sql — семь выборок.
- проверить.mjs — воспроизводимая проверка схемы, данных и прав; запросы.json — её вход.
- Результаты_проверки.json — версия движка, количества строк, результаты запросов, 21 проверка.
- Q01–Q07_результат.csv — результаты для чтения в Excel (UTF-8 BOM, разделитель ;).

Доступ DCL ограничен операциями над таблицами. RLS не включена. Привязку текущего пользователя, доступ к конкретной сделке, переходы статусов, неизменность согласованного КП, автоматический аудит и обмен внешними событиями должен реализовать сервисный слой. Статус заказа и журнал событий в наборе согласованы вручную. Триггеры проверяют состояние родителей при записи договора/заказа; полная защита от последующего изменения родителей требует дополнительных правил приложения и согласованных транзакций.

ИНН проверен только по форме (10 цифр). Цены не являются тарифами компании. Суммы разделены по валюте и периоду; данные не содержат правил НДС и не используются для расчёта реальных платежей.
