# Термины

**Клиент** — Юридическое лицо, которому предлагаются услуги.

**Сделка** — Учитываемая возможность продажи по потребности клиента.

**КП** — Коммерческое предложение с фиксируемыми версиями.

**Согласование** — Проверка условий конкретной версии КП уполномоченным участником.

**Договор** — Зарегистрированное основание для заказа; факт подписания подтверждается реквизитами и файлом.

**Заказ подключения** — Передаваемый во внешний контур набор работ или услуг.

**key** — Ключ идемпотентности команды создания заказа.

**eventId** — Уникальный идентификатор входящего события.

**Outbox** — Регистр исходящих событий, записываемых в транзакции с заказом.

**Inbox** — Регистр принятых событий для защиты от повторной обработки.

**RPO** — Допустимый интервал потери данных при восстановлении.

**RTO** — Целевое время восстановления работоспособности.
